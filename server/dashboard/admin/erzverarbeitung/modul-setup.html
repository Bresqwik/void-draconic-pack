Überblick

Modul-Bauweise: Enrichment – Laser Node – Smelting in einer Reihe. Jedes Modul ist gleich und wird nach Norden angehängt. Ein- und Ausgang (Node A und Z) gibt es nur einmal.

Zwei Kanäle – das Wichtigste

Kanal 0 · weiß Rohstoffe: Erze in die Maschinen, Staub in die Smelter.

Kanal 1 · orange Fertiges: alles, was in die Output-Kiste soll.

Ein Item geht immer nur zu einer Insert-Karte im selben Kanal, deren Filter es erlaubt. Gibt es mehrere, wird reihum verteilt.

Was wohin läuft

EiEisen, Gold, Kupfer … → Enrichment → Staub → beliebiger Smelter → Barren → Output
DiDiamant, Redstone, Kohle … → Enrichment → direkt Output
AlAluminium, Nickel, Silber … → Smelter → Output
UrUraninit, Shards, Inferium … → direkt Output

Bedienung in 30 Sekunden

Laser Node

  1. Rechtsklick auf den Node – das Fenster zeigt immer eine Seite.
  2. Oben die Seite wählen: U oben, D unten, N S E W = Himmelsrichtungen. Shift-Rechtsklick öffnet direkt die gegenüberliegende Seite.
  3. Item Cards in die 9 Slots dieser Seite legen. Mehrere Karten auf einer Seite sind normal.
  4. Rechtsklick auf eine Karte im Slot öffnet ihre Einstellungen.

Item Card

  1. Modus anklicken: Insert ↔ Extract (Stock/Sensor brauchst du nicht).
  2. Kanal: Farbfeld anklicken, bis weiß (0) bzw. orange (1).
  3. Zahlen (Priorität, Speed, Menge): Mausrad oder Klick – mit Shift in 10er-, mit Strg in 64er-Schritten.
  4. Unten: Filter in den Filter-Slot, Overclocker in den Overclocker-Slot.
Ohne Overclocker kann eine Extract-Karte nur 8 Items alle 20 Ticks bewegen. Jeder Overclocker: +16 Menge, −5 Ticks. 4 Overclocker = 64 Items jeden Tick.

Die 5 Filter

Tag Filter in die Hand → Rechtsklick in die Luft. Erz in den Slot legen, passenden Tag anklicken (oder eintippen). Für jeden Tag wiederholen. „Kein Staub“ auf Deny stellen, alle anderen bleiben Allow.

Für weitere Module kopieren

Karten: Card Cloner

  1. Card Holder ins Inventar, darin leere Tag Filter und Overclocker.
  2. Node von Modul 1 öffnen, Card Cloner auf den Mauszeiger nehmen.
  3. Linksklick auf eine fertige Karte = kopieren.
  4. Neuen Node öffnen, leere Item Card in den gleichen Slot, Rechtsklick mit dem Cloner = einfügen.
  5. Filter (mit allen Tags) und Overclocker nimmt der Cloner aus der Card Holder.
Reihenfolge: eine Kartenart kopieren und dann in allen neuen Nodes einfügen, dann die nächste Kartenart.

Factories: Configuration Card

  1. Shift-Rechtsklick auf die fertige Enrichment Factory = Seiten kopieren.
  2. Rechtsklick auf jede neue Enrichment Factory = einfügen.
  3. Dasselbe für die Smelting Factories.
  4. Upgrades (8 Speed, 8 Energy) von Hand einsetzen.
  5. Neuen Node mit dem Laser Wrench an den vorherigen Node hängen.
