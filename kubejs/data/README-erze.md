# Erz-Generierung: doppelte Metalle abgeschaltet

Almost Unified vereinheitlicht auf 1.20.1 nur Rezepte, nicht die Drops von Erzbloecken.
Deshalb werden doppelte Erze gar nicht erst generiert (Forge-Biome-Modifier auf "forge:none"):

- Immersive Engineering: Blei, Uran (Mekanism hat beide)
- Occultism: Silber (Immersive Engineering hat Silber)
