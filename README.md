<a name="progression"></a>
<p align="center"><img src="assets/readme/h-progression.svg" alt="Progression" width="100%"></p>

<p align="center"><img src="assets/readme/aeren.svg" alt="Sieben Ären: Ankunft, Grundlagen, Neue Welten, Industrie, Tiefe Magie, Wyvern, Chaos" width="100%"></p>

Das Questbuch führt in **sieben Ären** durch das Pack. Jede Ära schaltet die nächste frei, daneben gibt es Kapitel für jede große Mod, Bosse, Geheimnisse und Kopfgelder. Wer ein Kapitel abschließt, bekommt **Void-Kisten** – bei schweren Kapiteln mehr.

<a name="voidminer"></a>
<p align="center"><img src="assets/readme/h-voidminer.svg" alt="Der Void Miner" width="100%"></p>

<p align="center"><img src="assets/readme/voidminer.svg" alt="Die acht Stufen des Void Miners: Litherite bis Xerothium" width="100%"></p>

Der **Void Miner** aus *Environmental Tech* ist ein Multiblock mit Steuereinheit und Laser, der Erze, Ressourcen und Kristalle aus der Leere holt. Jede Stufe baut mit dem Kristall-Programm den Kristall der nächsten Stufe ab – von **Litherite** bis **Xerothium**, die letzten Stufen nur im End. Environmental Tech gab es nur bis 1.16.5; für dieses Pack wurde es auf 1.20.1 portiert.

<a name="installation"></a>
<p align="center"><img src="assets/readme/h-install.svg" alt="Installation" width="100%"></p>

<p align="center"><img src="assets/readme/install.svg" alt="Installation in vier Schritten" width="100%"></p>

1. **[Prism Launcher](https://prismlauncher.org/) installieren** und unter *Konten* mit dem Microsoft-Konto anmelden.
2. **Instanz importieren:** *Instanz hinzufügen* → *Importieren* → diesen Link einfügen → **OK**

   ```
   https://github.com/Bresqwik/void-draconic-pack/releases/latest/download/Void-Draconic-Prism.zip
   ```

3. **Starten.** Der erste Start lädt alle Mods und dauert ein paar Minuten. Danach kommen nur noch Updates, automatisch bei jedem Start.
4. **Mitspielen:** *Mehrspieler* → **Void &amp; Draconic**. Noch nicht freigeschaltet? Bei Stefan melden – er setzt dich auf die Whitelist.

> [!TIP]
> RAM (10 GB), Forge und Auto-Update sind in der Instanz schon eingestellt, Java 17 lädt Prism selbst. Fehlt der Server in der Liste: `mc-void-draconic.duckdns.org`

<details><summary><b>Ohne Import von Hand einrichten</b></summary>

1. In Prism eine Instanz mit Minecraft **1.20.1** und **Forge 47.4.26** anlegen.
2. [`packwiz-installer-bootstrap.jar`](https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest) in den Ordner `minecraft` der Instanz legen (Rechtsklick auf die Instanz → *Ordner*).
3. *Bearbeiten* → *Einstellungen* → *Eigene Befehle* → bei *Befehl vor dem Start* eintragen:

   ```
   "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/Bresqwik/void-draconic-pack/main/pack.toml
   ```

4. Unter *Java* den maximalen Speicher auf **10240 MB** setzen und starten.

</details>
